# 学习式落足点奖励：安全余量与合理步长

更新时间：2026-09-05

这份文档记录当前实现的奖励表达。它只修改学习式落足点的事件奖励，不修改电机动作奖励、AMP、MoE、状态机、Recovery 路由或摆动轨迹执行门控。旧表达已备份在
`docs/planner_reward_expression_before_margin_2026-08-26.md`。

## 坐标和事件

- 奖励只在 `learned_foothold_evaluated=True` 的规划事件产生；其他控制步为 0。
- 落点的前后/左右坐标使用本次 HOLD 冻结的支撑脚世界位置和身体朝向转换到的支撑脚局部坐标系。
- 前进分的原点是冻结的支撑脚，不是摆动脚起点，也不是名义落足点。
- `z` 仍由世界坐标地形查询得到；脚底外围点也转换到世界坐标后做危险圆柱检查。
- 最终奖励始终限制在 `[-1, 1]`。这不会把安全判定改成软判定：现有几何/执行门控仍按原逻辑生效。

## 四个奖励成分

### 1. 安全余量分

对脚底外围点计算到最近危险圆柱表面的有符号距离：圆柱外为正，侵入为负。取所有外围点中最小的距离，并以 `0.04 m` 为满分参考距离：

```text
没有侵入： safety_margin = clamp(min_signed_clearance / 0.04, 0, 1)
有侵入：   safety_margin = -(0.5 * 侵入点比例
                           + 0.5 * 总侵入深度归一化)
```

因此完全远离边缘得到接近 `+1`，靠近边缘分数连续下降；任何侵入都不会得到正的安全分。侵入点越多、总侵入越深，负分越大。最终规划奖励对侵入事件还会保留安全主导权，并把结果限制为不高于 `-0.05`，避免“少量侵入”被其他正项冲成正奖励。

### 2. 前进分

以冻结支撑脚坐标系中的预测落点计算等效步速度，与本次冻结的期望可行速度做有符号投影：

```text
沿期望方向且速度匹配：接近 +1
没有前进：             接近  0
反向后退：             接近 -1
```

该分只在名义点不安全且学习点安全的分支中参与评分。名义点安全时不再用
这个分干扰“复制名义点”的目标；真正与冻结命令相反的最终位移仍会得到负分，
但名义点过前时允许学习点相对名义点向后微调，只要最终位移仍符合命令方向。

### 3. 合理步长分

令投影速度与期望速度的比例为 `r`，使用：

```text
reasonable_step = clamp(1 - abs(r - 1), -1, 1)
```

理想步长 `r=1` 得到 `+1`；不动 `r=0` 为 `0`；反向或明显过大都会下降。这个项限制“越往前越高分”，但不会把向前的安全台阶点拒绝掉。

### 4. 名义点偏离项

名义点和学习点的水平距离使用学习式 planner 的调整边界归一化，而不是物理
可达椭圆。当前调整边界为前后 `12 cm`、左右 `10 cm`。偏离不超过 `2 cm`
时采用死区：

```text
完全一致： +1
0～2 cm：  从 +1 连续降到 0
超过 2 cm：沿当前方向继续变成负分，达到椭圆尺度为 -1
```

名义点安全时这个项是唯一评分项，促使学习点只做必要微调；名义点不安全
时它作为有限的接近代价，安全和命令方向信号优先，避免把网络锁在危险边缘
附近，也避免无理由跳到调整边界。

## 组合权重

名义点安全、学习点安全时：

```text
1.00 × 名义点偏离项
```

名义点不安全、但学习点没有侵入时：

```text
0.45 × 安全余量
+0.25 × 前进分
+0.10 × 合理步长分
+0.20 × 名义点偏离项
```

如果学习点有侵入，则使用安全主导的软学习信号：

```text
0.85 × 安全余量
-0.10 × 超出名义调整边界代价
-0.05 × 反命令方向代价
```

该分支仍然把侵入样本留给 PPO 学习，不用额外的拒绝逻辑替代奖励；但现有几何和摆动轨迹执行检查仍负责保护实际执行。

## 明确不加入的内容

本版本不加入“地形踏面分”。原因是当前任务已经有地形高度、可达椭圆和脚底外围危险圆柱检查；再增加一个踏面采样评分会重复计算，也会扩大训练和维护成本。后续若需要新增该项，必须单独定义数据来源和验证集，不能隐式混入当前安全分。
