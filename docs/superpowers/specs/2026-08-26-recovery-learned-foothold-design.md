# Recovery 学习式落足与有符号命令评分设计

## 目标

让 Recovery 中已经确认一只脚支撑时，另一只脚可以使用学习式 planner 的真实输出完成一次恢复摆动，并让 planner 获得有意义的安全与前进方向反馈；同时避免不可构造的三维目标进入动作策略。

## 已确认的原则

1. Recovery 不是重新采样很多次的自由探索阶段，而是一笔有明确起点、支撑脚和摆动脚的单支撑恢复事务。
2. 学习式 planner 仍输出支撑脚冻结坐标系中的绝对水平落点；目标高度由世界坐标地形查询补齐。
3. 危险圆柱侵入和摆动过程擦边属于连续学习信号。仿真训练中允许几何可构造的学习点执行，并按侵入点数量、总侵入深度和轨迹侵入给负奖励。
4. 高度查询失败、非有限数值、超出可达椭圆、目标与支撑脚高度差达到 `0.27 m` 或无法生成轨迹，属于几何无效，仍不可执行。
5. 一旦进入 SWING，支撑脚世界坐标、身体朝向、轨迹起点、目标世界坐标和抬脚高度全部锁定；支撑脚丢失立即废弃当前事务并回到 Recovery。
6. 同一支撑接触关系只发起一次恢复提案。提案失败不能在同一关系下每个控制周期重复采样；只有接触关系变化时才允许新事务。

## Recovery 数据流

```text
无可靠支撑 -> 保持 RECOVERY，不调用 planner
恰好一只脚确认支撑 -> 创建单支撑 HOLD 恢复事务
双脚确认支撑 -> 退出 Recovery，进入普通 HOLD

单支撑 HOLD:
  锁定支撑脚世界位置和身体朝向
  将另一只脚的当前真实世界位置作为轨迹起点
  生成解析名义恢复目标
  评估一次学习式落点
  查询学习目标世界高度
  检查几何有效性
  几何有效 -> 执行学习点，即使安全分为负
  几何无效 -> 不执行，保持 Recovery

执行后:
  支撑脚丢失 -> 丢弃事务并回到 Recovery
  恢复脚接触 -> 更新真实接触关系
  双脚接触 -> 普通 HOLD
```

单支撑恢复和正常双脚 HOLD 的区别只有启动条件与轨迹起点：恢复摆动脚已经处于任意真实空中状态，不能假定它从名义地面点起步；其余坐标冻结、目标锁定和触地验收遵循同一套机制。

## 命令方向评分

现有命令一致性是指数型非负值，无法明确惩罚“安全但向后退”的点。改为有符号连续分：

```text
候选落点隐含的水平位移投影到冻结期望速度方向：
  与期望同向并达到期望进展 -> 正分，理想值接近 +1
  基本不前进 -> 接近 0
  与期望反向 -> 负分，反向程度越大越接近 -1
```

安全名义点仍保留现有“完全一致 +1、2 cm 内连续下降到 0、超过 2 cm 连续下降到 -1”的距离分。名义点不安全时，安全性是必要结果，方向评分和适度偏离代价用于在多个安全点中优先选择继续前进且不过度远离名义意图的点。所有分数保持在 `[-1, 1]`，不增加新的米制阈值。

## 奖励与路由一致性

- Recovery 单支撑事务必须被记录为一次 planner 事件，不能被 `stabilization_active` 掩码成零奖励。
- Recovery 路由只放宽危险圆柱安全门，不放宽几何有效门；学习点几何有效时优先使用学习点，几何无效才不执行。
- 轨迹预检仍生成完整诊断，包括最深侵入和发生相位；Recovery 训练阶段不因危险圆柱侵入阻断可构造轨迹，但数值异常或轨迹无法生成仍失败。
- 正常 WALK 路由保持现有行为，不改变 AMP、MoE、电机 PPO、解析名义点、地形课程或观测维度。

## 验收标准

1. 单左脚或单右脚确认支撑时，下一控制周期最多产生一笔学习式恢复事务。
2. 无脚支撑时 planner 不产生恢复目标；支撑丢失时缓存立即失效。
3. 恢复学习点的侵入安全分为负时仍可在仿真中执行，并且 planner 事件奖励为负而不是零。
4. 几何无效目标绝不进入 SWING。
5. 有符号命令评分满足：同向 > 静止 > 反向。
6. 正常双脚步态、已有坐标冻结测试和全部落足模块测试保持通过。
